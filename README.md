# Human Narrative in the Age of AI

> AI 시대에 인간의 이야기는 무엇이 되는가. 질문을 세우고, 글로 쓰고, AI로 실험하고, 제품으로 만든다.
> What happens to human storytelling in the age of AI? Ask, write, experiment, build.

김호연(miru)의 작업 지도입니다. 네 층으로 나뉘고, 층마다 대표 저장소와 글이 하나씩 있습니다.

## 1. 질문 (Questions)
- 인간이란 무엇인가, 이야기는 왜 만드는가, 서사 콘텐츠는 어떻게 진화하는가 같은 물음을 Obsidian 노트로 정리합니다.
- 이 저장소의 시작 구조(Q001~Q004): 죽음이란 무엇인가 / 인간이란 무엇인가 / 인간은 왜 이야기를 만드는가 / 서사 콘텐츠는 어떻게 진화할까.

## 2. 글 (Writing)
- 블로그 [Miru Forest](https://forrest125.tistory.com) 의 `🤖 AI와 인간 서사` 카테고리: AI·VR·좀비·신화 같은 소재를 다룬 영화·드라마 분석 3편으로 시작했습니다.
- 같은 질문을 영화·드라마·IP 분석 글로 이어 갑니다.

## 3. 실험 (Experiments)
AI와 데이터로 콘텐츠를 만들고 평가해 보는 공개 저장소입니다.
- [k-drama-hit-predictor](https://github.com/kimble125/k-drama-hit-predictor), [k-show-hit-predictor](https://github.com/kimble125/k-show-hit-predictor): 한국 드라마·예능의 흥행을 지표로 추정하는 H-Score 프레임워크
- [webtoon-shortform-ai-planner](https://github.com/kimble125/webtoon-shortform-ai-planner), [cutmaster-webtoon-analysis](https://github.com/kimble125/cutmaster-webtoon-analysis): 웹툰의 강점을 분석해 AI 숏폼 기획으로 옮기기, 웹툰 성공 요인 데이터 분석
- [AutoAuthor](https://github.com/kimble125/AutoAuthor): 블로거를 위한 콘텐츠 기획·SEO 키워드 분석
- [zepeto-characterchat-monetization](https://github.com/kimble125/zepeto-characterchat-monetization): 제페토 캐릭터챗의 수익화·UX를 공개 데이터로 분석하는 대시보드

## 4. 시사 맥락 (News context)
- [aitimes-news-pipeline](https://github.com/kimble125/aitimes-news-pipeline): AI타임스 뉴스를 수집·정제·AI 요약·분석해 리포트로 만드는 CLI 파이프라인. 주간 AI 뉴스를 "콘텐츠 산업의 일", "고인 음성과 정체성" 같은 주제로 묶어 질문 층에 연결합니다.
